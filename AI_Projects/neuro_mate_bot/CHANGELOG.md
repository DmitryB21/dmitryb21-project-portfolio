# Changelog

## [0.1.0] - 2024-12-XX

### Добавлено
- ✅ Команда `/start` с приветственным сообщением и Reply-клавиатурой
- ✅ FSM для добавления задач:
  - Ввод названия задачи
  - Ввод времени выполнения в формате YYYY-MM-DD HH:MM
  - Валидация данных
- ✅ Просмотр списка задач с Inline-кнопками
- ✅ Изменение статуса задачи на "Выполнена"
- ✅ Удаление задач
- ✅ Команда `/report` для просмотра статистики
- ✅ Обработка неизвестных команд и сообщений
- ✅ Валидация входных данных (название, время, формат)
- ✅ Проверка прав доступа к задачам
- ✅ In-memory хранилище для задач

### Архитектура
- Модульная структура проекта
- Разделение на handlers, services, models, keyboards, states
- Test-First подход с описанием сценариев Given/When/Then
- Подробные комментарии в каждом модуле

### Документация
- `README.md` - основная документация
- `ARCHITECTURE.md` - описание архитектуры
- `USAGE.md` - руководство по использованию
- `tests/scenarios.md` - тестовые сценарии

### Технические детали
- Использование Aiogram v3
- FSMContext для управления состояниями
- ReplyKeyboard для основного меню
- InlineKeyboard для управления задачами
- Обработка ошибок и исключений
