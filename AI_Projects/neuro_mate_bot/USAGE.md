# Руководство по использованию бота

## Быстрый старт

1. **Установка зависимостей:**
```bash
pip install -r requirements.txt
```

2. **Настройка:**
   - Скопируйте `.env.example` в `.env`
   - Получите токен у [@BotFather](https://t.me/BotFather)
   - Вставьте токен в файл `.env`:
     ```
     TELEGRAM_TOKEN=your_telegram_bot_token_here
     ```
   - (Опционально) Получите API ключ OpenAI на [platform.openai.com](https://platform.openai.com/api-keys)
   - Добавьте ключ в файл `.env`:
     ```
     OPENAI_API_KEY=your_openai_api_key_here
     ```

3. **Запуск:**
```bash
python -m bot.main
```

## Команды бота

### `/start`
Запускает бота и показывает главное меню. Также сбрасывает текущий процесс (если вы были в процессе добавления задачи или сделки).

**Использование:**
- Отправьте `/start` в чат с ботом
- Или нажмите на команду в списке команд Telegram

### `/report`
Показывает статистику по закрытым сделкам за текущую сессию.

**Использование:**
- Отправьте `/report`
- Отображает количество закрытых сделок и общую сумму

## Основные функции

### Управление задачами

#### Добавление задачи

1. Нажмите кнопку **"Добавить задачу"**
2. Введите **название задачи** (например: "Подготовить отчет")
3. Введите **время выполнения** в формате `HH:MM` (например: `18:00`)

**Пример:**
```
Бот: 📝 Введите название задачи:
Вы: Подготовить отчет

Бот: ✅ Название сохранено: Подготовить отчет
     ⏰ Теперь введите время выполнения задачи в формате:
     📅 HH:MM
     Например: 18:00

Вы: 18:00

Бот: ✅ Задача 'Подготовить отчет' добавлена на 18:00
     📋 Статус: Не выполнена
```

**Важно:**
- Название не может быть пустым
- Время должно быть в формате `HH:MM` (например: `18:00`, `09:30`)
- Если указанное время уже прошло сегодня, задача будет создана на завтра

#### Просмотр задач

1. Нажмите кнопку **"Просмотреть задачи"**
2. Вы увидите список всех ваших задач

Каждая задача отображается с:
- Названием
- Временем выполнения (формат HH:MM)
- Статусом (❌ Не выполнена / ✅ Выполнена)
- Кнопками управления

#### Изменение статуса задачи

1. Просмотрите список задач (кнопка "Просмотреть задачи")
2. Найдите задачу со статусом "❌ Не выполнена"
3. Нажмите кнопку **"✅ Выполнена"** под задачей

Задача автоматически изменит статус на "Выполнена", и кнопка "✅ Выполнена" исчезнет.

**Уведомление:** После выполнения 2-й задачи бот отправит уведомление: "🎉 Ты выполнил 2 задачи! Ты крут!"

#### Удаление задачи

1. Просмотрите список задач
2. Найдите задачу, которую хотите удалить
3. Нажмите кнопку **"🗑 Удалить"** под задачей

Задача будет удалена безвозвратно.

### Управление сделками

#### Добавление сделки

1. Нажмите кнопку **"Добавить сделку"**
2. Введите **название сделки** (например: "Сделка с ООО Ромашка")
3. Введите **сумму сделки** в рублях (например: `85000` или `85000.50`)
4. Выберите **статус сделки** из предложенных кнопок:
   - Открыта
   - В процессе
   - Закрыта

**Пример:**
```
Бот: 📝 Введите название сделки:
Вы: Сделка с ООО Ромашка

Бот: ✅ Название сохранено: Сделка с ООО Ромашка
     💰 Теперь введите сумму сделки в рублях:
     Например: 85000 или 85000.50

Вы: 85000

Бот: ✅ Сумма сохранена: 85000 руб.
     📊 Выберите статус сделки:
     [Открыта] [В процессе] [Закрыта]

Вы: [Нажимаете кнопку "Закрыта"]

Бот: ✅ Сделка 'Сделка с ООО Ромашка' создана!
     💰 Сумма: 85 000 руб.
     📊 Статус: Закрыта
```

**Важно:**
- Название не может быть пустым
- Сумма должна быть положительным числом
- Статус можно выбрать только из предложенных вариантов

#### Просмотр сделок

1. Нажмите кнопку **"Просмотреть сделки"**
2. Вы увидите список всех ваших сделок

Каждая сделка отображается с:
- Названием
- Суммой (форматированной)
- Статусом с цветовым индикатором:
  - 🔵 Открыта
  - 🟡 В процессе
  - 🟢 Закрыта
- Кнопкой "Изменить статус сделки"

#### Изменение статуса сделки

1. Просмотрите список сделок (кнопка "Просмотреть сделки")
2. Найдите сделку, статус которой хотите изменить
3. Нажмите кнопку **"Изменить статус сделки"** под сделкой
4. Выберите новый статус из предложенных кнопок:
   - Открыта
   - В процессе
   - Закрыта

Статус сделки автоматически обновится, и сообщение перерисуется с новым статусом.

### Просмотр отчета

1. Отправьте `/report`
2. Вы увидите статистику по закрытым сделкам за текущую сессию

**Пример отчета:**
```
📊 За текущую сессию ты закрыл 3 сделки на сумму 150 000 рублей!
```

### Дополнительные функции

#### Получить совет по маркетингу

1. Нажмите кнопку **"Получить совет по маркетингу"**
2. Опишите вашу проблему или вопрос (например: "Как увеличить продажи?")
3. Бот отправит запрос в ChatGPT и вернет персональный совет

**Пример:**
```
Бот: 📝 Опишите вашу проблему или вопрос по маркетингу:
     Например: 'Как увеличить продажи?' или 'Как привлечь новых клиентов?'

Вы: Как увеличить продажи?

Бот: 🤔 Думаю над решением...
     [Через несколько секунд]
     
Бот: 📈 Совет по маркетингу:
     
     [Персональный совет от ChatGPT]
```

**Требования:**
- Необходим API ключ OpenAI в файле `.env`
- Если ключ не указан, бот покажет сообщение об ошибке

#### Получить мотивацию

1. Нажмите кнопку **"Получить мотивацию"**
2. Бот сгенерирует мотивационную фразу через ChatGPT и отправит вам

**Пример:**
```
Бот: 💭 Генерирую мотивацию...
     [Через несколько секунд]
     
Бот: 💬 [Мотивационная фраза от ChatGPT]
     
     💪 У тебя все получится!
```

**Требования:**
- Необходим API ключ OpenAI в файле `.env`
- Если ключ не указан, бот покажет сообщение об ошибке

## Отмена действий

В любой момент вы можете отменить текущий процесс (например, добавление задачи или сделки), отправив команду `/start`.

## Часто задаваемые вопросы

### Как изменить время выполнения задачи?
В текущей версии изменение времени выполнения не реализовано. Вы можете удалить задачу и создать новую с правильным временем.

### Можно ли использовать другие форматы времени?
Нет, время должно быть строго в формате `HH:MM`. Например: `18:00`, `09:30`, `23:59`.

### Что происходит с данными при перезапуске бота?
В текущей версии используется in-memory хранилище, поэтому все данные (задачи и сделки) теряются при перезапуске бота. В будущих версиях будет добавлена поддержка базы данных.

### Можно ли добавить задачу на прошедшее время?
Если указанное время уже прошло сегодня, задача будет автоматически создана на завтра с указанным временем.

### Как работает команда /report?
Команда `/report` показывает статистику только по **закрытым** сделкам за текущую сессию (с момента запуска бота). Она не учитывает задачи.

### Нужен ли API ключ OpenAI для работы бота?
API ключ OpenAI требуется только для функций "Получить совет по маркетингу" и "Получить мотивацию". Все остальные функции (задачи, сделки, отчеты) работают без него.

### Где получить API ключ OpenAI?
1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com)
2. Перейдите в раздел API Keys
3. Создайте новый ключ
4. Скопируйте ключ и добавьте в файл `.env`

### Что делать, если ChatGPT не отвечает?
- Проверьте, что API ключ указан правильно в файле `.env`
- Убедитесь, что у вас есть баланс на счету OpenAI
- Проверьте интернет-соединение
- Попробуйте позже, возможно, временные проблемы с API

### Как изменить статус сделки?
1. Просмотрите список сделок
2. Нажмите кнопку "Изменить статус сделки" под нужной сделкой
3. Выберите новый статус из предложенных вариантов

## Поддержка

При возникновении проблем:
1. Проверьте, что бот запущен
2. Убедитесь, что используете правильный формат команд
3. Попробуйте отправить `/start` для сброса состояния
4. Проверьте файл `.env` на наличие необходимых ключей
