# ТГ-Бот-помощник для менеджера по продажам и маркетолога

Telegram-бот на Aiogram v3 для управления задачами и сделками менеджера по продажам и маркетолога с интеграцией ChatGPT.

## Возможности

### Управление задачами
- ✅ Команда `/start` с Reply-клавиатурой
- ✅ Добавление задач через FSM (название → время в формате HH:MM)
- ✅ Просмотр списка задач
- ✅ Изменение статуса задачи на "Выполнена"
- ✅ Удаление задач
- ✅ Уведомление после выполнения 2 задач

### Управление сделками
- ✅ Добавление сделок через FSM (название → сумма → статус)
- ✅ Просмотр списка сделок
- ✅ Изменение статуса сделки (Открыта/В процессе/Закрыта)
- ✅ Команда `/report` для просмотра статистики по закрытым сделкам

### Дополнительные функции
- ✅ Получение совета по маркетингу через ChatGPT API
- ✅ Получение мотивационных фраз через ChatGPT API

## Архитектура

Проект использует модульную архитектуру:
- **handlers/** - обработчики команд и сообщений

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository_url>
cd neuro_mate_bot
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

5. Отредактируйте `.env` и укажите необходимые ключи:
```
TELEGRAM_TOKEN=your_telegram_bot_token_here
OPENAI_API_KEY=your_openai_api_key_here
```

- Токен Telegram бота можно получить у [@BotFather](https://t.me/BotFather) в Telegram
- API ключ OpenAI можно получить на [platform.openai.com](https://platform.openai.com/api-keys)

**Примечание:** Если вы не планируете использовать функции с ChatGPT (советы по маркетингу и мотивация), ключ `OPENAI_API_KEY` можно не указывать. В этом случае эти функции будут показывать сообщение об ошибке.
